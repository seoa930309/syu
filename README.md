# syu

## dayflow · 오늘의 흐름

캘린더 · 아이젠하워 매트릭스 · 시간대 흐름을 한 화면에서 관리하는 할 일 웹앱 (`index.html`).

GitHub Pages 주소: https://seoa930309.github.io/syu/

> 할 일 데이터는 각 브라우저의 localStorage에 저장되므로 기기마다 따로 저장됩니다.

### 사용법
- **계획 붙여넣기**: ChatGPT가 짜준 계획 텍스트를 붙여넣으면 날짜별로 나눠 등록해요. 마크다운 목록, 표, 그냥 줄글 모두 읽어요. 등록 전에 미리보기에서 날짜, 제목, 종류를 고칠 수 있어요.
  - **GPT 요청문 복사** 버튼을 누르면 이 앱이 가장 잘 읽는 형식으로 계획을 다시 써달라는 요청문이 복사돼요.
  - **최근 붙여넣기 취소**를 누르면 마지막으로 가져온 항목을 한 번에 지워요.
- **일정 / 할 일 구분**: 약속·시험·병원처럼 날짜가 정해진 것은 *일정*, 해야 할 공부나 과제는 *할 일*이에요.
  - 일정은 캘린더에 둥근 모양으로 표시되고 시간을 넣을 수 있어요.
  - MATRIX와 FLOW 화면에는 할 일만 들어가고, 그날의 일정은 목록 위에 따로 보여요.
  - 캘린더 오른쪽 위에서 전체·일정·할 일 중 골라서 볼 수 있어요.
- **색상 설정**: 위쪽 팔레트 버튼을 눌러 일정과 할 일의 기본색을 원하는 색으로 바꿀 수 있어요. 무지개 칸을 누르면 아무 색이나 고를 수 있어요.
  - 항목 하나만 다른 색으로 하고 싶으면 편집 창에서 고르면 돼요. **A** 칸을 고르면 다시 기본색을 따라가요.
  - 같은 창의 **매트릭스 사분면**에서 네 칸의 색을 각각 바꿀 수 있어요. **A** 칸을 고르면 원래 디자인으로 돌아가요. FLOW와 캘린더의 사분면 표시 점도 같은 색을 따라가요.
- **할 일 카드**: 제목 앞의 `[과목]`은 자동으로 떼어서 색이 붙은 작은 라벨로 보여줘요. 제목은 두 줄까지 보여요.
  - 왼쪽 네모를 누르면 완료, **⋯**을 누르면 편집·위로 올리기·즐겨찾기·삭제 메뉴가 열려요. 카드 빈 곳을 누르면 편집 창이 열려요.
- **캘린더**: 할 일 막대 앞에 과목 색 띠와 줄임말이 보여요(예: 신경, 물치). 과목 색과 줄임말은 색상 설정에서 바꿀 수 있어요.
  - 폰에서는 막대가 색 띠로만 보이고, 날짜를 누르면 캘린더 아래에 그날의 일정과 할 일이 펼쳐져요.
- **포커스 타이머** (뽀모도로 · 타임트래킹): 위쪽 시계 버튼을 누르면 어느 화면에서든 타이머가 떠 있는 창으로 열려요.
  - 제목줄을 끌어 옮기고, 아래 양쪽 모서리를 끌어 크기를 바꿔요. 제목줄을 두 번 누르면 화면 가득 ↔ 원래 크기로 바뀌어요.
  - **TIMER** 탭에서는 크게 볼 수 있어요. 팝업과 탭은 같은 타이머라서, 옮겨도 계속 돌아가요. 돌아가는 동안 시계 버튼에 빨간 점이 떠요.
- **스크롤바**: 할 일 목록, 매트릭스 칸, 시간대 목록이 넘치면 옆에 항상 보이는 스크롤바가 생겨요(맥·폰 포함). 막대를 끌거나 빈 곳을 눌러 이동해요. 카드를 끌어 목록 위·아래 끝에 대면 자동으로 스크롤돼요.

### 앱으로 설치하기
사이트(https://seoa930309.github.io/syu/)를 연 뒤:
- **아이폰**: 사파리 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드**: 크롬 → 위쪽 **앱 설치** 버튼(또는 메뉴 → 앱 설치)
- **PC**: 크롬·엣지 → 위쪽 **앱 설치** 버튼(또는 주소창 오른쪽 설치 아이콘)

설치하면 홈 화면 아이콘으로 주소창 없이 열리고, 인터넷이 없어도 열려요.

### 화면 크기 맞춤
- 위쪽 한 줄에 날짜, 화면 버튼(캘린더·매트릭스·플로우·타이머), 도구가 모두 들어가요. 폰에서는 도구가 **⋯** 메뉴로 들어가요.
- 캘린더는 화면 높이에 맞춰 한 달이 들어가게 줄어들어요. 바쁜 주는 높게, 빈 주는 낮게 나눠요. 그래도 다 안 들어가면 할 일을 숨기지 않고 오른쪽에 항상 보이는 스크롤바가 생겨요.
- **타이머만 보기**: TIMER 탭 오른쪽 위 버튼이나 타이머 팝업의 ⛶ 버튼. 검은 화면에 원형 타이머만 화면 가득 보여요(컴퓨터는 전체 화면). 화면 빈 곳을 누르거나 스페이스바로 시작·일시정지, 숫자를 누르면 시간 입력, 테두리를 끌면 시간 맞추기. 나가기 버튼이나 Esc로 돌아와요.

### 과목 관리
위쪽 **과목 관리** 버튼(폰은 ⋯ 메뉴 안)에서:
- **추가**: 새 과목 이름을 쓰고 + 추가
- **이름 바꾸기**: 이름 칸을 고치고 엔터. 그 과목의 할 일도 모두 바뀌어요. 이미 있는 과목 이름으로 바꾸면 두 과목을 합칠지 물어봐요.
- **색 · 줄임말**: 색 칸과 줄임말 칸을 바꾸면 바로 반영돼요.
- **삭제**: × 버튼. 할 일은 남고 과목만 빠져요.
- **이수**: 다 들은 과목은 **이수** 버튼을 누르면 아래 **이수 완료** 칸으로 따로 모여요(접었다 펼 수 있어요). 할 일 편집 창의 과목 추천에서도 빠져요. **되돌리기**로 다시 수강 중으로 옮겨요.

### 브레인 덤프
캘린더 위쪽 **뇌 모양 버튼**을 누르면 떠 있는 메모 창이 열려요.
- 떠오르는 걸 적고 Enter. 여러 줄을 붙여넣으면 한 줄씩 들어가요. `[과목] 내용`으로 쓰면 과목도 붙어요.
- 항목을 **캘린더 날짜로 끌어다 놓으면** 그날 할 일이 돼요. **→ 9/24** 버튼은 지금 고른 날짜로 바로 보내요.
- 글자를 누르면 고칠 수 있고, ×로 지워요. 창은 옮기고 크기를 바꿀 수 있어요.

### 글씨
- 글씨체: **1984대화나눔 본문체** (`fonts/` 폴더, Light · Regular · Bold). 캘린더의 필기체 달 이름과 타이머 숫자는 원래 글씨체를 써요.
- 글씨 크기: 위쪽 **팔레트 버튼 → 글씨 · 색상 설정 → 글씨 크기**에서 80% ~ 140%로 조절해요.
